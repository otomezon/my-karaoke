# v1.3 仕様対応表

| 仕様領域 | 実装 | 備考 |
|---|---|---|
| 曲一覧・お気に入り | 対応 | 下部3ナビ、一覧カード上でお気に入り切替 |
| 曲登録・編集・削除 | 対応 | 曲名必須、任意アーティスト、200文字、重複候補、関連履歴の一括削除 |
| 曲詳細 | 対応 | 統計、採点履歴、編集・削除メニュー |
| 採点入力 | 対応 | ボトムシート、数字キーボード指定、5桁固定、入力プレビュー |
| 採点履歴 | 対応 | 追加・編集・削除、5秒取り消し、日時編集 |
| 統計 | 対応 | 平均・最高点・回数・最終歌唱。整数単位で平均を丸める |
| 検索 | 対応 | 曲名・アーティスト部分一致、空白除去、NFKC、小文字化 |
| 絞り込み・並び替え | 対応 | 4絞り込み条件、8並び替え条件、安定した同順位処理 |
| IndexedDB | 対応 | songs / scoreRecords / settings、曲削除と履歴削除を同一トランザクションで処理 |
| バックアップ | 対応 | JSON書き出し、アプリ識別子・スキーマ・日時付き |
| 復元 | 対応 | 全体検証後に置き換え／追加、ID競合時は既存データを上書きしない |
| PWA | 対応 | Manifest、アイコン、Service Worker、アプリシェルキャッシュ |
| オフライン | 対応設計 | 初回オンライン読込後、キャッシュされたアプリとIndexedDBで動作 |
| ダークテーマ | 対応 | スマートフォン優先、セーフエリア、可変画面幅 |
| 表示倍率固定 | 実装 | viewport指定と touch-action。OS・ブラウザのアクセシビリティ操作までは保証しない |

## 仕様上の留意点

- 初期仕様どおり点数は `0.000`〜`99.999` の範囲です。100.000点は扱いません。
- 採点履歴1件を歌唱1回として集計します。
- 保存先はブラウザのオリジン単位です。ブラウザや配信URLを変える前にバックアップしてください。
- オフライン起動はService Workerによる初回キャッシュ取得後に利用できます。
